# 柴火创客学院 · 设计

这份文档只写三类东西：这个站是什么、做设计判断时用的范式、以及代码里看不出来
的事实与硬约束。具体的色值、间距、组件长什么样，以代码和 `/styleguide`
（`pnpm dev` 后打开）为准，不在这里抄一遍。

---

## 1. 这个站是什么

面向教育机构决策者（校长、信息中心主任、集成商负责人、企业培训负责人）的
B2B 招生招商站。先锋官与基地是我们招募的渠道伙伴，不是终端客户。

核心叙事，贯穿所有文案（授人以渔）：

> 我们培养人掌握新技术整合能力，让团队自己能把解决方案部署落地。

**招牌资产是 M0–M6 × L1/L2/L3 课程矩阵**，相当于 SaaS 站的产品截图。
访客记住这个站，应该是因为它。

## 2. 设计范式

做任何视觉或版式决定前先过一遍。它们是判断方法，不是尺寸表。

- **每页一个主角。** 先说清这一页让人记住的那一样东西（首页和 /courses 是
  矩阵），把大胆用在它身上，周围保持安静。两处都想抢眼，就删一处。
- **开场就是论点。** 首屏放这一页最有特征的东西，而不是「大标题 + 副题 +
  三个数字」的模板。首屏每个元素都要回答访客的一个问题，答不出就删。
- **结构即信息。** 编号、小标签、分隔线、色阶只在它编码了真实信息时才用：
  编号要求内容真的有顺序，色阶要求真的有深浅（L1 → L3 的黄色就是）。
  只为好看而加的结构是噪音。
- **渐进披露。** 概览层只放做决定需要的信息，细节放到下一层，并且让通往
  下一层的入口一眼可见、可点的东西看起来就可点。同一条信息只在一处讲透。
- **内容决定版式。** 七门课的源材料深浅不一。区块跟着内容走：有料才渲染，
  没料就不出现，不为了对齐而凑字或留空壳。
- **字体承担性格。** 得意黑是这个站的声音，克制使用才有分量；正文负责
  清楚。靠字号、字重、留白拉开层级，不靠加框加底。
- **文案是设计材料。** 按钮写清点击后会发生什么；同一个去向全站一种说法；
  名词和数字优先于形容词。
- **动效要么有编排，要么没有。** 一个设计过的时刻胜过处处在动。零散的
  淡入、滑动、hover 花样会让页面显得像生成的。
- **做减法收尾。** 完成后在浏览器里看真实页面（zh 和 en），再拿掉一样东西。
  自问：这是为这个站做的选择，还是换个题目也会这么做的默认值？

质量底线不用声明、但必须做到：窄屏可用、键盘焦点可见、正文对比度不低于
4.5:1、尊重 `prefers-reduced-motion`。

## 3. 颜色

色值唯一来源是 `src/data/themes.ts`。每个主题是同一组角色 token 的一套取值，
`<html data-theme>` 决定哪一套生效；换色调改 `defaultThemeId`，预览在任意页面
加 `?theme=<id>`。

组件里只写角色名，不写色相名（red / yellow / black）和裸 hex：

| 角色 | 用在哪 |
|---|---|
| `background` / `foreground` | 画布 / 标题与正文 |
| `inverse` / `inverse-foreground` | 深色面及其文字 |
| `primary` / `primary-foreground` / `primary-hover` | 主行动的填充、其上文字、hover |
| `primary-ink` | 浅色面上的主色文字与图标 |
| `accent` / `accent-foreground` / `accent-soft` / `accent-ink` | 强调填充与浅强调面 |
| `strong` / `module` (+ `-foreground`) | 徽章与模块牌 |
| `level-1` / `level-2` / `level-3` | 学习深度色阶，由浅到深 |
| `neutral-1` … `neutral-10` | 结构灰阶，1 最浅 |

填充色上的文字用配对的 `*-foreground`，不要默认写 `text-white`。
新增主题时，文字组合要过 4.5:1。

## 4. 字体

- 得意黑 Smiley Sans：display，hero 标题、section 标题、站名。
- Inter → Noto Sans SC：正文与界面。
- JetBrains Mono：只给拉丁代号（`M2`、`L1`、`3d`、SKU）。中文不套 mono、
  大写、宽字距。

两个代码里看不出来的坑：

- 得意黑是**子集字体**。标题里出现子集外的字，会在一行中间掉回正文字体，
  check / lint / build 都发现不了。改了标题文案后跑
  `python3 scripts/subset-display-font.py <完整字体路径>`。
- 得意黑没有日文汉字字形，日语页面的标题整行用正文字体。

## 5. 文案声音

一个真的在开课的教研团队在回合作方邮件：说课时、说设备型号、说验收、敢说
边界。「不交付 / 不承诺」清单是全站最稀缺的信任资产，保留。

不用的语域：

- 营销黑话：赋能、打造、一站式、助力、抓手、轻松实现。
- 模板装置：每个模块复用同一句引言或脚注；与标题同义的小标。
- 内部代号外泄：未解释的缩写、数据 schema 术语。
- 日式词与直译词：学园、之旅、解锁、拥抱。见 `.claude/rules/i18n-text.md`。

全站不写价格数字，只给行动话术。面向访客的每个数字和事实，在
`src/data/*.ts` 的注释里要有出处，没有出处就删。

## 6. 硬约束

1. 不伪造信任信号：没有出处的数字、占位合作伙伴 logo、AI 生成的仿真实拍。
   图像优先级：真实照片 > 真实产品图 > 统一扁平插画。
2. 不做 brutalist：粗黑边、硬阴影、偏移阴影、装饰几何块、整段主色铺面。
3. 不放内嵌表单：合作入口是邮箱。
4. 逻辑按稳定 `id` 分支，不按显示文案（`label.includes('…')`）。
5. 界面文案的 key 五个语种同一次提交补齐；zh 文案不在 i18n 字典里重写一遍。
